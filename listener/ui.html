Settings backup

ExportSaves every setting here, voice mode and your muted threads to a file you choose. The pad profile is saved next to it as its own XML file. The connection token is never included
ImportReplaces all settings with the ones in an exported file. The current settings are saved first, dated, in the settings-backups folder. Import the pad profile separately, from the Macropad tab
