Pad profiles

https://voiceloop.dev/pad-profile/1 is the XML namespace for voiceloop pad profiles. A profile describes one macropad model: its USB IDs, keys, knobs, light modes and key map. voiceloop reads it to draw the pad in Settings and to program it.

  • pad-profile.xsdThe schema. Every element and attribute, with notes.
  • ch57x-3key-knob.xmlThe built-in profile: 3 keys and a knob, USB 1189:8890.

Make a profile for your pad

  1. Find the pad's USB ID. In Windows, open Device Manager, find the pad under Human Interface Devices or Keyboards, and open Properties, Details, Hardware Ids. It looks like VID_1189&PID_8890.
  2. Export the current profile. In voiceloop, open Settings, Macropad, and under Pad profile press Export…. You get an XML file to edit.
  3. Edit it to match your pad. Change the name, the vendorId and productId on <usb>, the keys and knobs it has, and their codes. The schema above explains each one.
  4. Import it. Back in Settings, Macropad, press Import…. voiceloop saves the profile it replaces first, dated, in the pad-profiles folder. Start again puts the built-in pad back.
  5. Upload a key map and try every control. If a key does the wrong thing, check its code in the profile.

One protocol so far

A profile only describes the pad. The bytes that program it come from a built-in encoder, and voiceloop has one: ch57x-8890, for CH57x pads with USB ID 1189:8890. If your pad uses another protocol, a profile can't fix that yet. Open an issue with its USB ID and an exported profile.
